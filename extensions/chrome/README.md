# Agentrix Chrome Extension

Manifest V3 sidepanel extension. Opens an Agentrix chat sidebar inside any
Chrome tab.

## Features

- 🔲 **Side panel chat** — full-height Agentrix chat without leaving the page
- ⌘ **Ctrl+Shift+A** — open the sidebar from anywhere
- 📄 **Summarize page** — one-click summary of the active tab
- 📌 **Right-click → Ask Agentrix about "…"** — selection-driven prompts
- 🔑 **Token-based login** — paste your Agentrix API token, never see it in URL bars

## Install (developer mode)

1. Visit `chrome://extensions`
2. Toggle **Developer mode** (top right)
3. Click **Load unpacked** and select the `extensions/chrome/` folder
4. Pin the extension; click it to open the side panel
5. Paste your Agentrix token (issue one at https://agentrix.top/account/api-keys)

## Files

- `manifest.json` — MV3 manifest, sidePanel + commands + contextMenus permissions
- `background.js` — service worker, handles command/menu/messaging
- `sidepanel.html` / `sidepanel.css` / `sidepanel.js` — UI + chat client
- `icons/icon{16,32,48,128}.png` — generated by `generate-icons.ps1`

## Build / package

The extension is plain JS/HTML/CSS — no bundler needed. To create a `.zip`
ready for the Chrome Web Store:

```powershell
Compress-Archive -Path *.json,*.js,*.html,*.css,icons -DestinationPath agentrix-extension.zip
```

## Backend endpoints used

- `POST https://api.agentrix.top/api/claude/chat` — streaming SSE chat
- `https://agentrix.top/account/api-keys` — token issuance (web)
