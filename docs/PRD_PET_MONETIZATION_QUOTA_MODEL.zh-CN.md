### 3.3 配额扣减规则

```typescript
// backend/src/modules/pet-generation/pet-gen-quota.service.ts（V4 W3 新增）

interface PetGenQuotaUsage {
  userId: string;
  month: string;        // 'YYYY-MM'
  planLevel: 'free' | 'pro' | 'pro_plus';
  monthlyQuotaUsed: number;
  monthlyQuotaLimit: number;
  overageGenerations: number;
  overageBilledUSD: number;
  resetAt: Date;
}

// 提交生成时
async function submitGeneration(userId: string, mode: GenMode) {
  const usage = await getOrInit(userId);
  
  if (usage.monthlyQuotaUsed < usage.monthlyQuotaLimit) {
    usage.monthlyQuotaUsed += 1;
    return { billed: false };
  }
  
  // 超额，需用户主动确认
  const ok = await requireUserConfirm(userId, {
    cost: 0.5,  // USD
    reason: '本月配额用完',
  });
  if (!ok) throw QuotaExceededAndDeclined;
  
  usage.overageGenerations += 1;
  usage.overageBilledUSD += 0.5;
  await chargeViaSubscriptionGateway(userId, 0.5);
  return { billed: true, amount: 0.5 };
}

// 失败时回滚
async function refundOnFailure(userId: string, taskId: string) {
  const usage = await getOrInit(userId);
  if (task.wasOverage) {
    usage.overageBilledUSD -= 0.5;
    usage.overageGenerations -= 1;
    await refundViaSubscriptionGateway(userId, 0.5);
  } else {
    usage.monthlyQuotaUsed -= 1;
  }
}
```

## 4. Marketplace UGC 经济（最大长期增长）

### 4.1 抽成模型

```
基础抽成：
  Agentrix 平台 30% / 创作者 70%
  
有 Remix（二创）：
  原作者 A 上架皮肤 A，设置 Remix 分成比例 r ∈ [10%, 50%]
  二创者 B 用 PetCreator 双图融合产生皮肤 B
  B 上架售价 P，售出时：
    Agentrix 30%
    A 收 (P × 70%) × r
    B 收 (P × 70%) × (1-r)
  
3 层祖先上限：A → B → C → D，D 之后所有上游归入版权金池
版权金池：用于 DMCA 假冒赔付与社区奖励
```

### 4.2 上架形态

| 形态 | 描述 | 平台抽成 | 适用 |
|------|------|:-:|------|
| **一口价售卖** | 一次性买断 | 30% | 大众皮肤 |
| **拍卖** | 起拍价 + 出价递增 + 截止时间 | 30% + 0.5% 转账费 | 限量 / IP 联名 |
| **租赁** | 按月租用 | 30% | 季节性 / 节日 / 试用 |
| **免费上架** | 引流 / 营销 | 0%（创作者无收益） | 病毒 / Showcase |

### 4.3 拍卖规则

```
最低起拍价：$1
最高拍卖时长：7 天
出价加价幅度：5%
反狙击：截止前 1 分钟内出价 → 自动延长 2 分钟
最高出价者支付：成交价 + Gas（链上凭证可选）
未成交：起拍方可重新上架
```

### 4.4 租赁规则

```
租金区间：$0.5 - $20 / 月
租期：1 / 3 / 6 / 12 月
租客权限：使用 + 显示，不可二次出租 / 转售 / Remix
租期结束：自动归还，租客 PetSkin 表 active=false
延期：租期内可续租，价格按上架时为准
```

### 4.5 反盗版机制

| 机制 | 实现 |
|------|------|
| **反向图搜查重** | CLIP embedding + Faiss index，新皮肤上架前对比已有库 |
| **链上凭证（可选）** | 用户付费 $1 铸造 ERC-721 → 真伪可验 |
| **DMCA 流程** | 表单 → 48h SLA → 验证 → 下架 + 抽成回收 |
| **假信号惩罚** | 恶意 DMCA 1 次 → 警告；2 次 → 失去 DMCA 权；3 次 → 封号 |
| **版权金池** | 平台 30% 抽成里 5% 留作金池，用于 DMCA 赔付 |
| **风控积分** | 用户总分（举报正确率 / 上架质量 / 投诉率），低分限流 |

### 4.6 上架审核

```
新皮肤提交上架
   ↓
前置过滤（< 1s）：
  - 文件格式（.vrm / .glb 必须通过结构验证）
  - 文件大小（< 50 MB）
  - 多边形数（< 50k for L3, < 5k for L2）
   ↓
自动审核（< 30s）：
  - CLIP NSFW 评分
  - 反向图搜查重
  - 关键词扫描元数据（名称 / 描述）
   ↓
✅ 通过 → 直接上架
⚠️ 高风险 → 人工复核（24h SLA）
❌ 拒绝 → 返还配额 + 提示原因
```

### 4.7 销售结算

```
买家付款

   ↓
T+0 立即可见（"待结算"状态）

用户可申请提现（≥ $10）
```

## 7. 单宠物日预算上限（防成本爆炸）

### 7.1 LLM 调用成本预算

```typescript
// backend/src/modules/agent-account/budget-policy.service.ts（扩展）

interface PetBudgetPolicy {
  petId: string;
  
  // 用户感知预算（用户钱包扣）
  userVisibleDailyUSD: number;     // Free: 0, Pro: 5, Pro+: 50
  
  // 平台成本预算（平台承担，控制亏损）
  platformDailyLLMUSDCap: number;  // 防止单宠物烧爆
  platformPerTaskLLMUSDCap: number;
  
  // 模型分级路由
  modelRouting: {
    cheap: ['gpt-3.5-turbo', 'claude-haiku', 'qwen-turbo'];
    standard: ['gpt-4o-mini', 'claude-sonnet'];
    premium: ['gpt-5', 'claude-opus'];  // 仅 Pro+ 高价值任务
  };

```

### 7.2 单宠物日预算（按计划）

| 计划 | 用户钱包日预算 | 平台 LLM 成本日上限 | 单任务上限 |
|:-:|:-:|:-:|:-:|
| Free | $0 | $0.5 | $0.05 |
| Pro | $5 | $3 | $0.5 |
| Pro+ | $50 | $20 | $2 |
| 企业 | 合同 | 合同 | 合同 |

> 平台 LLM 成本上限防止：例如 Pro 用户启用了一个失控的 Auto-Earn 任务无限循环 → 后端拒绝继续推理。

### 7.3 异常检测

- 单宠物 1 小时内 LLM 调用 > 100 次 → 暂停 + 告警
- 单宠物日成本超限 → 立即冻结 + 通知用户
- 单宠物日内多次任务失败 > 5 次 → 暂停 24h
- 异地登录 / 突发大额任务 → L3 强制审批

| 订阅 14 天内 | 全额退 | 24h |
| 订阅 14 天后 | 按未使用月份比例退 | 48h |
| PetCreator 失败 | 自动退配额 + 退款 | 即时 |
| Marketplace 买到假货 | 全额退 + 卖家受罚 | 7 天 |
| Auto-Earn 任务失败 | 视情况，平台不保证 | 申诉 7 天 |
| 硬件 30 天内未拆 | 全额退 | 7 天 |
| 硬件 1 年内非人为损坏 | 免费保修 | 14 天 |

### 9.2 反作弊机制

| 类型 | 防御 |
|------|------|
| **刷单（Auto-Earn）** | 任务来源白名单 + evaluator 检查质量 + 同 IP 多账号检测 |
| **Marketplace 自买自卖** | 同支付指纹 / 同设备 / 同 IP 检测 |
| **Remix 链路滥用** | 3 层祖先上限 + 单笔上限 + 频率限制 |
| **配额滥用** | 单设备 / 单 IP 注册速率限制 + 邮箱验证 |
| **重复账户** | 设备指纹 + 行为聚类 + 怀疑账号转人工 |
| **退款滥用** | 退款率 > 30% 标记，限制后续 |
