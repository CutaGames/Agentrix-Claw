# World（世界）模块 Audit + 增长/变现玩法建议（2026-06）

> 目标:盘点 World 现状(真实 vs 脚手架)、补齐项,并给出"能把用户拉进来体验、甚至付费"的高 ROI 玩法。
> 结论先行:**底座比想象中扎实**(创作生命周期/发现/经济/实时/A2A 网关都在),最大缺口是
> **「agent 让每个游戏活起来」这条差异化主线还没落到主力游戏上**,以及**玩法验证(分数权威)+ 竞技/榜单/remix**
> 这几个能直接拉留存与消费的闭环没接通。

---

## A. 现状盘点(基于代码核查,标注真实度)

### ✅ 已落地且可用
- **创作生命周期**:create / publish / moderate / 状态机 / 发现一致性(discoverable 才可进入/被调用)。
- **发现**:feed(hot 排序 + personalization)+ map(已重做为可视地图)。分享落地页 `/c/:code` + 精美海报(含官网下载)。
- **游戏**:clone-mutate 10 个原型 + play-test 闸门 + 自修复;embed/import 外链;**两款实时对战**
  (五子棋 Gomoku / Pong,含 vs AI + 多人,复用 /aeon 实时层)。
- **互动剧 MVP**:DramaRunner(场景/选择/AXP 解锁/打赏/TTS),demo 走通。
- **店铺/交易**:offerings + **服务端权威购买**(AXP 买家→卖家)+ 打赏;**Agent 网关 A2A 调用**
  (额度核销 / 权威定价 / 审计 / metrics 回流)——人端与机器端同一份权威逻辑。
- **经济**:抽成模型(一级 5% / 二级 30%)、AXP 充值(Stripe + 移动 IAP)、分档返现、Agent 预设额度。
- **实时直播/舞台**:LiveRoom 真多人(在场/聊天/举手/上麦/打赏),复用 aeon 网关。
- **现实(O2O)**:到店 GPS 签到 → AXP 奖励(POI 绑定,半径判定)。
- **社交数据层**:like / comment / follow 实体 + service 已存在。

### 🟡 部分/脚手架(进入但内容空 or 未接通)
- **「进入体验」对 place/world 类型基本是空的**:`CreationExperienceService.enter()` 对无 ECS 快照的
  地理/场所类创作返回**空世界**(可漫游但啥也没有)。即 game/drama/shop/live 之外的类型"进去是空房间"。
- **AI 对手/陪练只在 Gomoku/Pong**:10 个 HTML5 语料游戏都是**单机**,没有 AI 陪玩。
  ——这正是战略文档里 **#1 差异化("每个游戏一进去就有 agent 陪你打")还没兑现到主力游戏**。
- **没有 `render_game_to_text()` 约定**:play-test 只能验"没崩",验不了"分数会涨/能通关";
  也因此**做不了分数权威 → 没法做可信榜单/竞技奖池/反作弊**(OSS 调研里点名的高 ROI 借鉴点)。
- **Remix/血缘分润没有**:抽成只按"owner 是否原创"分一级/二级(本质是转手),**没有 fork→衍生→给原作者分润**
  的创作飞轮(战略文档承诺的 remix 血缘没实现)。
- **创作级榜单缺失**:榜单散落在别处(宠物模仿秀赛季 / 宠物迷你游戏 / aeon AXP 榜 / 签到榜),
  **World 创作/游戏本身没有"本周热门/高分榜"**。
- **社交未充分前台化**:like/comment/follow 有数据层,但详情页互动 + "关注"流 tab 基本没露出。

### ❌ 缺失(但有现成基建可低成本接)
- 玩法验证→分数权威→竞技/奖池/反作弊整条链。
- 限时赛季 / 活动(基建在宠物侧已有,World 没复用)。
- 直播带货闭环(LiveRoom 有在场+打赏,缺"边看边买 offerings")。
- 可玩广告 / 品牌定制小游戏(clone-mutate 让这条几乎零边际成本,未商业化)。

---

## B. 必修:补齐体验质量(让"进来"不空、不掉)
1. **空体验兜底**:place/world 进入时若无内容 → 引导"让 AI 现场生成一个玩法/小剧/店铺",或落到
   一个默认可玩 demo,杜绝"进去是空房间"。
2. **`render_game_to_text()` 约定**(借 game-creator):给 10 个语料游戏 + LLM 产物都暴露状态 JSON。
   → play-test 升级为"玩法真的通"(断言 score↑ / over 可触发),并为 ③④ 的 AI 对手 + 榜单铺路。**地基级。**
3. **社交前台化**:CreationDetail 露出点赞/评论/关注 + 新增"关注"创作流 tab(数据层已就绪,低成本)。

---

## C. 吸引进来 + 促消费的玩法(按 ROI 排序;均基于现有基建可落地)

### P0 —— 最高 ROI,直接拉 Wow + 留存 + 消费
1. **每局都有 AI 对手/陪练 + 可「召唤」别人的 agent 当 Boss/陪练/代打**(战略 #1)。
   - 通用先做"AI 解说/教练"(任何游戏即时点评/给招),再做品类对战(match3 双人对消、射击协作、棋类对弈)。
   - **消费点**:召唤强力 agent 陪练/代打/上榜收 AXP;agent 擂台(赢的 agent 可被雇佣,打通 agent 市场)。
   - 基建:已有 vs AI(Gomoku/Pong)+ agent 网关 + 召唤页;缺的是把 agent 接入 HTML5 游戏循环(靠 ②的状态文本)。
2. **每周创作/高分榜 + 技能对赛 AXP 奖池**(需②分数权威)。
   - 每个游戏"本周高分榜";赛季奖池:报名费(AXP)→ 奖池 → 前几名瓜分(**纯技巧,非随机,规避博彩**;地区合规待法务)。
   - **消费点**:报名费 + 复活/加成道具;**留存**:每周重置、榜单攀爬。
3. **Remix 血缘分润**:任意创作可一键 fork → 改参数/换皮/续写 → 成交时按血缘给原作者分润。
   - **增长**:UGC 飞轮 + 病毒扩散;**消费**:remix 解锁/高级模板。基建:抽成模型已在,扩成 lineage 即可。

### P1 —— 高 LTV / 强差异化
4. **互动剧"追更" + 活体 agent 演角色**(对标 ReelShort,但 agent 是它给不了的差异化)。
   - 按集解锁(已有)+ 角色好感/分支 + **剧外可召唤角色 agent 继续聊**。**消费点**:解锁、打赏、角色互动订阅。LTV 最高。
5. **直播带玩/带货**(LiveRoom 已有在场+打赏):主播开播,观众**边看边买** offerings + 打赏 + agent 协同主持。
   - **消费点**:打赏 + 直播专属商品成交抽成。
6. **限时赛季 / 活动**:复用宠物侧赛季基建到 World(节日主题创作赛、投票、冠军奖池)。拉日活与回流。

### P2 —— B2B / O2O 高毛利(中期)
7. **可玩广告 / 品牌定制小游戏**:clone-mutate 让生成近乎零成本 → 品牌出钱投放给 agent 经济受众。**高毛利 B2B。**
8. **真实商家 O2O**:到店签到(已有)→ AXP → **可核销优惠券**;商家付费上架/投放。

## D. 变现路径汇总
- **已有**:AXP 充值(Stripe/IAP)、购买 offerings、打赏、互动剧解锁、订阅档位、Agent 预设额度、返现。
- **建议新增**:竞技报名费/奖池、remix 血缘分润、皮肤/盲盒(装饰性,非 P2W)、直播带货抽成、可玩广告(B2B)、O2O 券核销。
- **合规红线**(沿用战略文档):不做投机代币/P2E;对赛先做"纯技巧+非赌"形态,下注类待法务;可玩广告需广告标识。

---

## E. 落地优先级(建议顺序)
1. **P0-②`render_game_to_text` + 分数权威**(地基,解锁榜单/竞技/AI 对手/反作弊)。
2. **P0-① AI 解说/陪练注入 HTML5 游戏**(先通用解说,再品类对战)——立刻拉开与 Astrocade 体感差距。
3. **P0-② 每周高分榜 + 赛季奖池** + **B-③ 社交前台化**(留存与传播)。
4. **P0-③ Remix 血缘分润**(UGC 飞轮)。
5. **P1-④ 互动剧追更 + 活体角色**(高 LTV)。
6. **P1-⑤⑥ 直播带货 / 赛季活动**;**P2 B2B/O2O**。

> 一句话:World 的"管道"已经通(创作/发现/交易/实时/A2A),现在该把**「agent 让游戏活起来」+「玩法验证→竞技榜单→remix 飞轮」**
> 这两条主线接上——它们既是别人抄不了的 Wow,又直接对应报名费/打赏/解锁/分润等可收的钱。
