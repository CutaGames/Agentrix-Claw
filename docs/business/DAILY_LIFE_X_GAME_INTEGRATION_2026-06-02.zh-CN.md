# 日常生活需求 × 永曜城游戏 融合设计(2026-06-02)

诉求:用户日常的衣食住行/自主交易等真实需求,如何**和游戏结合、在游戏中实现**,而不是把"工具"
和"游戏"做成两张皮。本文给出设计原则 + 具体玩法 + 落地分期,全部基于已有底座(不重造)。

---

## 核心理念:真实办事 = 游戏内的"行动",真实价值 = 游戏内的经济

永曜城已有四原语(房间/舞台/任务/组织)+ 经济层(AXP/钱包)+ 现实闭环 `reality-loop`。
日常服务融合的关键不是"在游戏里塞一个外卖按钮",而是把**真实世界的办事行为映射成游戏内的角色行动**,
让"用 agent 办成一件真事"既产生真实结果,又在游戏世界里留下痕迹(产出/AXP/声誉/新闻)。

三条已存在的桥:
- `reality-loop.service.ts`:现实任务/Computer Use 完成 → 世界奖励(`aeon_reality_reward` 已是 AXP earn 来源)。
- `world-news`:世界动态流(可把"某人 agent 帮主人订到了票"写成一条城市新闻)。
- Org/任务广场:真实代办可以是"任务契约",由 agent 员工承接完成。

---

## 具体融合玩法(从轻到重)

### A. "派 agent 出门办事" = 游戏内角色离场办真事(最自然的融合)
- 在永曜城里,用户点自己的 agent 角色 → "派 TA 去办事"(订票/查天气/发邮件/盯加密行情)。
- agent 角色在场景里切到 `agent` 控制态、头顶 🤖,精灵播放"外出/办公"动画离场;
  后台真实调用对应连接器(OpenAPI/MCP/Computer Use)。
- 办完回到城里,头顶冒"✅ 订到 6/10 北京→上海 ¥xxx",并:
  - 写一条 world-news("XX 的 agent 完成了一单出行预订");
  - 发 `aeon_reality_reward` AXP 到钱包(真实办事→游戏奖励);
  - 在"任务广场"留一条已完成记录(可复盘)。
- **复用**:agent 控制态(R2/R3 已实现)+ reality-loop credit + world-news + 连接器执行。

### B. 真实服务 = 城里的"店铺/设施"(把服务空间化)
- 把每类服务做成永曜城里一栋功能建筑(已支持功能建筑→Room,#2 P2 已做):
  "出行社"(订票)、"外卖摊"(点餐)、"交易所"(自主交易)、"邮局"(发邮件/日历)。
- 点进"交易所"建筑 = 进入一个房间场景,里面就是加密行情 + 让 agent 下单的面板(底层 trading/x402)。
- 真实商家入驻(见 WORLD_REALWORLD_FEASIBILITY)后,这些店可以是真实商户的游戏门面。

### C. 真实代办 = 任务广场的悬赏(人/agent 互助经济)
- 用户发"帮我订一张周五去上海的高铁,预算 ¥600"为一条任务契约(已有 task 原语)。
- 自己的 agent 员工、或别人的 agent、或真人,都能接单完成 → 完成发 AXP(已有发薪/结算闭环)。
- 这把"自主交易/代办"变成**多人 + 多 agent 的协作经济**,而不是单机工具。

### D. 真实习惯 = 游戏养成(衣食住行的"住"和日常)
- 真实日历/健康/打卡(已有 wearable/vitals 模块)→ 喂养主宠、提升角色等级、解锁城建。
- "今天喝够水/走够步/完成日程" → 宠物长大、领地解锁新建筑。把自律变成养成正反馈。

---

## 与"插件库"的关系
- 插件库(连接器市场)是**供给侧**:决定 agent 能办哪些真事。
- 永曜城是**需求侧 + 体验层**:把办事行为变成有代入感、有经济、有社交的游戏循环。
- 两者通过 reality-loop + 经济层 + world-news 缝合:**装的连接器越多 → agent 在城里能干的活越多 → 产出/AXP/声誉越高**。

---

## 落地分期(全部复用已有底座)
- **P1(2~3 天)**:玩法 A 最小闭环。AeonScene 给 agent 角色加"派去办事"入口 →
  调一个已通的连接器(如天气/机票查询/加密行情)→ 回来发 `aeon_reality_reward` AXP + 写 world-news。
  这是"真实办事↔游戏"最短可玩闭环,验证理念。
- **P2**:玩法 B。把 2~3 类服务做成城里功能建筑(出行社/交易所/邮局),点进去是服务房间。
- **P3**:玩法 C。真实代办接进任务广场(发悬赏→agent/真人接→完成结算),接 D 的养成反馈。
- **P4**:真实商家门面(依赖 WORLD_REALWORLD_FEASIBILITY 的商家入驻)。

## 一句话
不要把"工具"和"游戏"分两张皮:**让"用 agent 办成一件真事"本身就是游戏里的一次行动** ——
有动画、有产出、有 AXP、有城市新闻、有协作。底座(agent 控制态 / reality-loop / 经济 / 任务 / 功能建筑)
都已就位,P1 用一个有 API 的连接器就能把这个闭环演示出来。
