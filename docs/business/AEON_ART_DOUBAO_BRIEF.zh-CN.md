> 用途:Aeon 平行世界目前所有建筑/场景都是 **emoji 占位**(🏢/📋/🛒…)。本文给豆包/即梦

## 0. 整体世界观与画风基调(每条 prompt 都要带的"前缀")

**世界设定**:Aeon「永曜城」——一座漂浮在天空中的科技未来城。真人和 AI agent 共同
居住、开公司、接任务、办活动。基调要"温暖科技感",不要冷硬赛博朋克。

> **基调已定稿(2026-05-31 门禁通过)= "晨昏暖光 A'"**:暖色天空(蜜桃橙→淡紫渐变)+
> **中性偏暗的青蓝等距网格地面** + 克制霓虹点缀。霓虹深夜只作"夜间档"(靠程序昼夜滤镜实现),
> **不作默认底色**。所有图统一用下面这段晨昏暖光关键词。

**统一画风关键词(建议每条 prompt 都粘这段)**:
```
2.5D 等距视角(isometric, 2:1 斜俯视),Q版可爱卡通游戏美术,科技未来城风格,
背景是温暖的晨昏天空(蜜桃橙到淡紫渐变),柔和发光霓虹(青色/暖金)只作克制点缀,
主体明亮干净,圆润造型无尖锐写实细节,柔和上色无粗黑描边,
色调温暖治愈不阴暗,类似《纪念碑谷》+《星露谷》+《浮岛物语》融合,
游戏资产风格,画面干净,高质量。
```

**必须避免(每条 prompt 末尾粘这段负面词)**:
```
避免:真实照片写实风、赛博朋克阴暗脏乱、深夜霓虹满屏、过曝、文字水印、人物真人脸、
粗黑描边漫画风、杂乱背景、第一人称视角、正面平视视角。
```

> ⚠️ 一致性提示:豆包逐张生成容易漂色/漂风格。**以已定稿的 CA-1 为"风格锚图"**,
> 后续每张都用"以这张图的配色和画风为参考(图生图/参考图模式)"来生成,保证整套统一。

> ⚠️ **重要:底图/建筑里不要画宠物或角色!** 游戏里的宠物/角色是程序运行时用
> `PetSpriteImage` 单独渲染叠加上去的(玩家会移动/增减/换族群),**不画进美术资产**。
> 让豆包"把宠物摆进某个格子"是徒劳的(它控制不准也不需要)——底图保持空地即可。

## 1. 第一步:概念图验证集(门禁必出,3 张)

这 3 张是量产前的画风验证关卡,先出这 3 张给团队评审(见门禁文档 §5)。

### CA-1 · 等距地块俯视(✅ 已定稿 — 晨昏暖光 A' 空地版)
**用途**:地块/小镇外观基调 + 后续所有图的风格参考锚。**已通过门禁**(见 `AEON_CONCEPT_ART_REVIEW` §6)。
```
[粘 §0 画风前缀]
画面内容:一块漂浮在晨昏暖色天空中的正方形等距地块(isometric 2:1 俯视),
重点是【一大片干净、空旷的可建造地面】:中性偏暗的青蓝等距地砖铺成的平整广场,
表面带清晰但柔和的等距网格质感(像棋盘格,暗示可放置)。
建筑【只在地块四条边缘少量点缀】:几盏光柱路灯、1-2 棵发光霓虹树、低矮发光栏杆;
【中央 70% 面积完全留空,不放任何建筑、不放任何宠物或角色】。
地块边缘是悬浮岛的发光蓝边界,下方是淡紫色云雾。天空蜜桃橙到淡紫渐变。
地面颜色中性偏暗,霓虹只作点缀不铺满,以便后续叠加明亮的小角色时角色清晰凸显。
整体明亮干净、极度留白、构图居中、俯视角度统一。
[粘 §0 负面词]
比例:1:1 正方形,1024×1024。
```
> 交付用"空地无角色"版;带宠物的样张仅作可读性验证存档。

### CA-2 · 模块化建筑外观一套(5 个功能建筑同图)
**用途**:建造目录贴图方向验证。
```
[粘 §0 画风前缀]
画面内容:在纯透明/纯色背景上,等距视角并排展示 5 栋 Q 版科技未来城建筑,
每栋之间留间隔、互不重叠,风格统一:
1) 公司总部楼:4×4 占地的圆润高层办公楼,蓝金配色,顶部发光 logo 位;
2) 任务公告台:2×1 的发光全息公告牌立柱;
3) 市场货架:2×2 的霓虹摊位/货架,挂暖黄灯;
4) 舞台穹顶:4×3 的半透明发光穹顶舞台,品红光;
5) 会议舱:3×3 的圆润玻璃会议舱,青色光。
全部等距同一角度、同一光源、同一画风。
[粘 §0 负面词]
比例:16:9 横图,1536×1024。
```

### CA-3 · 室内氛围背景(公司办公室)
**用途**:房间室内静态背景(角色站在前面)。
```
[粘 §0 画风前缀]
画面内容:一间 Q 版科技未来城公司办公室的等距室内场景,作为游戏房间背景:
柔和发光的工位、全息屏幕、绿植、暖色灯光,空间通透,中间和前景留出空地
(给 Q 版角色站位用),背景不要太满、不要抢角色。氛围温暖、专注、未来感。
[粘 §0 负面词]
比例:16:9 横图,1920×1080。
注意:这是背景图,前景中下部要相对干净,方便叠加角色立绘。
```

**评审通过标准**(对照门禁文档):等距角度统一、霓虹科技感成立、留白够放建筑/角色、
现有 chibi 宠物精灵叠上去读得清。通过 → 进第 2、3 步量产。

## 4. 第四步(可选增强):昼夜滤镜不需要出图

昼夜/天气是**程序单层全屏滤镜**(晨/昼/暮/夜 + 雨雾),客户端一个半透明 overlay 叠色实现,

## 6. 出图优先级(给你/豆包排期)

1. **先出 CA-1**(风格锚图)→ 团队看一眼对不对路。
2. 对了再出 **CA-2 + CA-3**(凑齐门禁 3 张)→ 走门禁评审。
3. 门禁过 → 出**建造目录高频 5 项**(hq-tower / task-board / market-stall / stage-dome / meeting-pod,即"功能建筑")。
4. 再出**装饰 5 项** + **房间背景 5 张**。
5. 不通过 → 在门禁文档 §6 记失败原因(如霓虹太脏/角色读不清),调 prompt 重出。

> 一致性兜底:若豆包跨张漂得厉害,改用"固定参考图 + 图生图"模式,或只让豆包出**定妆/概念**,
> 量产切帧交给美术用同一参考图细化。任一资产缺失 → 代码自动回退 emoji 占位,不崩。
