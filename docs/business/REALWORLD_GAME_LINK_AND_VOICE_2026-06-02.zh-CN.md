## 一、现实 ↔ 游戏 双向关联玩法(让两个世界互相喂养)

核心原则:**现实里发生的事改变游戏世界的状态;游戏里的经营反过来驱动现实里的行动。**
不是单向"办事→发币",而是双向闭环。已有底座:`reality-loop.service`(双向)、`world-news`、
经济层、wearable/vitals、Computer Use、连接器。

### A. 现实数据 → 游戏世界形态(现实塑造你的城)
- **天气**:你所在城市今天下雨 → 永曜城你的领地也下雨(同步天气连接器);连续晴天解锁"丰收" buff。
- **运动/健康**(已有 wearable/vitals 模块):今天步数/心率达标 → 宠物长大、领地长出新植被、解锁建筑。
- **作息**:现实熬夜 → 宠物显示疲惫;规律作息 → 宠物精神、产出加成。
- 价值:**把自律/健康变成养成正反馈**,现实越规律,游戏世界越繁荣。

### B. 游戏经营 → 现实行动(游戏驱动你办成真事)
- 公司接了一个"现实 KPI"(如"本周读完一本书/跑 3 次步")→ agent 在游戏里盯进度,
  现实完成(连接器/手动打卡确认)→ 公司产出 + 发薪。游戏的经营目标 = 现实的自我管理目标。
- 游戏里 agent "提醒事项"→ 触发现实通知/日历(已有 buildAssistantIntent reverse-call 通道)。

### C. 现实资产 → 游戏资产(拍了就有,已打通)
- 拍现实物体 → 成为游戏建材/宠物(本轮已打通"拍照做素材建造")。现实的东西"搬"进游戏。

### D. 现实行情/事件 → 游戏经济(世界与真实市场同频)
- 加密行情连接器:BTC 大涨 → 永曜城"交易所"建筑播报 + 持仓玩家获 buff;
- 现实重大日子(生日/节日)→ 城市办活动(接活动系统)。

### E. 群体现实成就 → 全服世界事件(社交 × 现实)
- 全服玩家今日总步数突破阈值 → 解锁全服节日/限定建筑;把个人现实行为聚合成集体游戏目标。

### 推荐落地顺序(都复用已有底座)
1. **A-天气同步**(最快,连接器已有 weather):领地天气跟随现实城市 → 立刻有"两个世界相连"的体感。
2. **A-健康养成**(wearable/vitals 已有):步数→宠物成长/领地解锁。
3. **B-现实 KPI 公司任务**:把公司 KPI 任务支持"现实完成确认",游戏经营=现实自我管理。
4. D/E 进阶。

## 二、会议室在线语音对话 — 现状与落地路径

### 现状(诚实)
- 已有 `/voice` 实时网关(`realtime-voice.gateway.ts`),但它是 **1:1(用户 ↔ AI)**:
  session 维度,STT→LLM→TTS,**不是多人对多人的群组语音**。
- Aeon 会议室/房间走 `/aeon` 网关(在场 + 文字 chat + 舞台),**目前没有语音**。
- 真·多人实时语音(每个人说话别人实时听到)需要 **WebRTC + SFU**(mediasoup/LiveKit)——
  是一块独立的实时音频基础设施,工作量大(服务器媒体转发、回声消除、带宽、移动端原生 WebRTC)。

### 三档落地路径(由轻到重)
- **L1 语音转文字发言(本轮可做的最短增量,推荐先做)**:
  会议室里"按住说话"→ 复用 `/voice` 的 STT 把你的话转成文字 → 通过 `/aeon` 房间 chat 广播给全场。
  体感:你用"说"代替"打字",全场实时看到你的发言。AI 主持/agent 可 TTS 念出回应。
  **不需要 SFU,复用两个已有网关**,1~2 天可落地。
- **L2 AI 语音主持/播报**:会议室一个 AI 主持,把房间内文字/事件用 TTS 播报(单向语音),
  营造"现场有人在说"的氛围。复用 `/voice` TTS。中等工作量。
- **L3 真·多人实时语音(WebRTC SFU)**:接 LiveKit(自托管或云)或 mediasoup。
  每人麦克风实时混流,真正的语音会议。大工程,需专门 sprint + 媒体服务器成本。建议有明确需求 + 用户量后再投入。

### 建议
先做 **L1(语音转文字发言)**:用户在会议室/广场/直播厅能"说话发言",全场实时可见,
且 AI 能语音回应 —— 这已经给到"在线语音交流"的核心体感,且完全复用现有 STT/TTS + /aeon 房间,
不引入 WebRTC 重型依赖。L3 真群组语音作为明确的后续大版本。
