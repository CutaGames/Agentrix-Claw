- 0-10s：温暖钢琴（日常感）
- 10-30s：节奏渐强的电子乐（工作/创造）
- 30-45s：轻快弹跳（经济/交易）

## 制作建议

### 视觉风格
- 主色调：深蓝渐变 (#0B1220 → #1a2a4a) + 品牌绿/紫点缀
- 3D 宠物：使用 VRM 模型实时渲染或预渲染
- UI 展示：真实产品截图 + 轻微动效
- 转场：流体/粒子过渡（呼应"灵魂"概念）

### 音效设计
- 宠物诞生：水晶音 + 轻微电子脉冲
- 跨端切换：流水般的"嗖"声
- 赚钱提示：硬币轻响 + 正向音效
- 拥抱/触摸：温暖的低频嗡鸣

### 多语言版本
- 中文版：面向国内市场，强调"AI 宠物"概念
- 英文版：面向全球，强调"AI Agent Economy"
- 日文版：面向日本市场，强调"電子ペット"情感连接
