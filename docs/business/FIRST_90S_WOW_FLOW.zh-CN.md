# 新用户前 90 秒「Wow」流程设计 + 玩法串联(2026-06-04)

## 目标
新用户进来 90 秒内体验到一次"哇",并把现有彼此孤立的玩法
(拍照创角 / 战斗 / AXP / 永曜城圈地 / 社交)串成一条有反馈、有下一步的引导线,
解决"做完一步不知道下一步该干嘛、玩法很散"的问题。

## 现状盘点(已核实代码,2026-06-04)
| 玩法 | 状态 | 游客可用? | 反馈 |
|---|---|---|---|
| 拍照→AI 角色卡 | ✅ 真实,秒级出卡(名字/属性/技能/立绘),3D 后台孵化 | ✅ 是(本地预览不落库) | 角色卡炸出=核心 wow |
| 训练战斗(打假人) | ✅ 真实,赢得 XP | ❌ 登录后(后端 `interactive/train` 对游客 403) | 升级 + XP 飘字 |
| AXP 增长 | ✅ 真实(签到 +15、跑腿 +15) | ❌ 需登录(+GPS) | 钱包数字跳动 |
| 永曜城圈地 | ✅ 真实 | ❌ 需登录 | "圈地成功"+进入领地 |
| 新手引导编排 | ❌ **之前完全没有** | — | — |

**关键结论**:游客只能体验"拍照创角"这一个 wow;战斗/AXP/永曜城都在登录后。
所以最佳转化点 = **角色卡出现的情绪峰值,立刻引导保存(=注册)**,注册后立刻给"首胜 + AXP 红包 + 落地永曜城"作为回报。

## 90 秒脚本
- **0–12s 钩子**:落地页「拍一下身边的东西 → 变成会战斗的 AI 角色」→ 相机。
- **12–40s 创角(WOW)**:拍 1 张 → 几秒角色卡炸出(杯子→"Mighty Mug Lv.1",有属性/技能)。游客即可。
- **40–52s 转化**:卡片态正是峰值 → 「保存 TA 并带去战斗」→ 一键注册。
- **52–78s 首胜**:注册后进一场简单训练战(易胜)→ 赢 → 升级 + XP 飘字。
- **78–90s 经济+世界钩子**:赢后「把 TA 安置到永曜城」→ 圈第一块地 → "TA 住进真实地图了,看看附近还有谁"。

闭环串联:创角 → 注册 → 战斗 → (AXP) → 永曜城 → 社交。
