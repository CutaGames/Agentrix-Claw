## 0. 一句话愿景(候选)

> **"一个你和你的 AI 一起生活、一起赚钱、一起共建的平行世界。"**
> 人类与各自的 AI 伙伴(萌宠)搬进一座新城,在这里生活、开公司、办活动、赚真实
> 的钱(AXP / 数字货币),城市的繁荣由每个居民的真实努力一点点建成;建完地球,
> 还能殖民火星、探索银河。

**北极星场景(待用户最终拍板一句):**
示例 — *"我在 Agentrix 办了场黑客松,我的 agent 替我全程对接了 20 个项目方,
第二天醒来发现它帮我谈成了一个外包单,赚了 50 USDC。"*

## 1. 三个独有内核(市面上没有产品同时具备)

1. **双控位(Dual Avatar)** — 同一个角色,既能真人亲自上,也能交给 agent 托管,
   还能"协同(co-pilot)"。三态:
   - 亲自(Manual):真人实时操作(开会发言、KTV、自己打 boss)
   - 托管(Agent):AI 自主跑(上班打卡、刷日常、夜里替我经营)
   - 协同(Co-pilot):人给目标 AI 执行,人随时夺回(开会 AI 记纪要)
2. **真实价值双向流通** — 发布/接受真实世界任务,世界里赚真钱(AXP→数字货币),
   远期甚至交易现实物资。世界不是消耗时间的游戏,是产生价值的场所。
3. **多模态共同在场** — 开会/KTV/看电影/上课/上班打卡/打怪,都是"一起做一件事"
   的容器,游戏化的皮、底下是真实协作。

## 2. 底层四原语(所有场景都由这四件配置出来,不为每个场景写死功能)

> 关键落地纪律:**一个原语做穿,而不是十个场景做浅。** 黑客松/freetalk/公司/开会
> 看似很杂,本质是下面四件的组合。

| 原语 | 定义 | 承载的场景 |
|---|---|---|
| **房间 / 场所 (Room/Venue)** | 一群人(真人+agent)同时在场的虚拟场所 | 会议室、KTV、影厅、教室、工位、副本、活动会场 |
| **舞台 (Stage)** | 房间的变体:一对多 + 上麦/排队 + 观众席 + 售票/打赏 | freetalk 脱口秀、峰会演讲、路演 |
| **任务 / 契约 (Quest/Contract)** | 有发起方/承接方/验收/报酬的协作单元 | 真实任务、悬赏、打怪、公司 KPI、作业 |
| **组织 (Org)** | 临时或长期的人+agent 集合,带账本 | 黑客松队伍(临时)、OPC 公司(长期)、活动主办方 |
| **经济 (AXP/钱包)** | 贯穿一切的价值层 | 工资、门票、赏金、交易、版税 |

> 备注:Org 在表里单列,但与"活动主办方"同构 —— 办活动=临时组织,开公司=长期组织,
> 底层都是"组织 + 房间 + 任务 + 账本"。

## 3. 关键场景设想(都是四原语的配置)

### 3.1 活动(黑客松/会展/峰会)= 获客飞轮
- 主办方/项目方在世界里办活动 → 自带流量导成 Agentrix 用户(B2B2C)。
- **"活动是获客的楔子,世界是留存的家"** —— 活动结束场地不消失,参与者角色留在世界。
- 角色分工:主办方开活动(议程/组队/奖池AXP/任务) · 参与者报名→组队→签到→提交→拿
  AXP/出席徽章(POAP式) · 平台抽成/赞助位/把人流转留存。
- agent 也能"参会":替我听峰会 + 记纪要 + 标记关心议题(双控位)。

**Agentrix 该办的黑客松(产出回流生态,奖品=作品成为生态一部分+持续分成):**
- "造一个 Skill" → 优胜上架 Skill 市场
- "养一个最能打工的 Agent"(非程序员也能比,呼应 OPC 用户)
- "造一个世界玩法/房间"(UGC,复用 WorldGameRuleSet)
- "Agent 创业 48 小时"(组队开虚拟 OPC 接真实任务赚 AXP,直接验证核心闭环)
- 赞助/命题黑客松(外部厂商出题+出奖池,带流量带钱)

### 3.2 OPC 公司 = 北极星用户 + "虚拟公司"落地(第五问题眼)
- **OPC(一人公司)创业者 = 程序员之外最重度的 AI 使用者**;一个人靠 agent 团队干
  市场/运营/财务/客服 —— 这就是 Agentrix 原生形态(一人指挥一群 agent)。
- 满足 OPC → 小团队 → 企业,清晰向上路径。
- 公司=组织实体:agent 员工(我的+雇来的) · 工位(打卡) · KPI(任务) · 账本(AXP)
   · 对外门面(接单页/招聘页)。
- **打卡上班** = agent 在公司房间按时跑任务,产出可计量、可发薪。
- **招聘** = 雇佣别人的 agent/角色打工发 AXP 工资 = 经济+社交+任务三合一。
- **现实激励/配套资源部署进去**:真实孵化器/补贴/云代金券/API额度/投资机会,作为世界里
  的资源点/任务奖励/商店货架;达成里程碑解锁真实资源。→ Agentrix 成为"AI 创业者的
  虚拟产业园 / 孵化器入口",资源方/政策方主动来投放(又一获客+变现来源)。

### 3.3 Free Talk / 脱口秀 = 舞台原语,补情感娱乐维度
- 随时上麦 freetalk / 进去听 / 售票 / 打赏 / 常驻演员入驻分成。
- AI 独特玩法:agent 上台讲脱口秀/主持/捧哏;托管态替我听场+给摘要;真人+AI 同台
  (分得清谁是谁,反而是看点)。
- **教训(Clubhouse 之死):纯实时房间留不住人,必须有沉淀** —— 录播、片段、关注、
  常驻。世界正好是沉淀容器。

### 3.4 交易市场 / 任务广场 / 悬赏中心(后端底座已大量具备)
- 任务广场:日常任务(发布/接单/验收/付AXP)—— 高频黏性。
- 悬赏中心:高价值真实任务(escrow 托管赏金、竞标、里程碑)—— 低频高价值。
- 交易市场:资产(Skill/皮肤/角色/道具)买卖 + 二创版税。

## 4. 现实 × 游戏 双向闭环(代入感来源)

- **现实 → 游戏**:工作(agent任务/Computer Use)→金币+科技;学习(专注时长)→升级;
  运动出行(步数/定位)→活力+解锁区域;扫描现实物体→世界居民/道具;真实 agent 战绩
  →能力加成(已有 abilitySnapshot 飞轮)。
- **游戏 → 现实**:世界任务触发现实动作(提醒喝水/番茄钟/日历 —— 已有 14 个 intents 桥);
  世界产出 AXP→真实可用。

```
活动(黑客松/峰会)──获客──▶ 用户进入世界
      ▲                              │
 主办方/项目方付费投放                 ▼
 政策方/资源方投放真实资源        创建/加入 OPC 公司
      ▲                       ┌──────┴──────┐
      └── 达成里程碑解锁 ──   真人亲自干    agent 托管干
                              └─ 任务/雇佣/发薪(AXP→真钱)─┘
                                        │
                                        ▼
                                 真实价值产出 + 留存
```

## 5. 美术方向(有主张的建议)

**定调:2.5D 等距(isometric)、暖色治愈风的"AI 萌宠 × 真人 数字游民小镇 / AI 产业园"。**

理由:
- **复用现有资产** —— 现有 2D chibi 横版精灵条(灵狐/猫头鹰/鲸/熊,256px 帧)可直接贴
  到斜 45° 地图上走动,不重做角色。
- **3D 不现实** —— World Engine 3D 重建一直失败/超时/贵;手机实时多人 3D = 性能带宽
  灾难。实时社交世界必须轻。
- **等距天然 = 房间/街区** —— 美术形态和系统架构是同一件事。

美术分层(都能 AI 批量产 + 少量人工把关风格,延续现有出图路子):
1. 等距 tile 地块 + 模块化建筑外观(公司楼/剧场/市场/会场)
2. 室内 = **静态氛围背景大图 + 角色站位**(最省,室内不建模)
3. 角色复用现有族群精灵;真人/agent 同身体不同标识
4. 6 族群配色 = 6 种街区视觉母题(办公科技蓝/生活樱花粉/学习藏青暖黄/娱乐荧光橙/
   Web3深海金/家庭焦糖暖)
5. 昼夜/天气 = 一层全局色彩滤镜(低成本高回报)
- **扫描造物统一过 cartoon style transfer**(已有 styleType:'cartoon' 字段),守住画风一致。

参考气质:布局像 Gather/oVice,画风像动森/星露谷的圆润治愈,角色是 chibi AI 萌宠。

## 6. 剧情 / 世界观(薄外壳 + 厚涌现,不写死主线)

- **薄世界观外壳**(给世界一个"为什么",见 §0 一句话)。
- **三层涌现内容,不靠编剧:**
  1. 个人微剧情:升级现有 world-sim tick 事件流为 LLM 生成的小故事(已有 Bedrock)。
  2. 文明演进剧情(借 Civilization):全城真实活动累积推动时代演进(拓荒→集镇→都市→…),
     每跨代解锁建筑/玩法/地标(奇观)。这是长期叙事脊柱。
  3. 社交涌现剧情:真实发生的事(谁接了谁的单、哪场 freetalk 爆了、谁公司产出第一)
     自动变成世界新闻/八卦/排行榜。
- 载体复用:世界新闻栏(升级事件流)、里程碑/奇观、有性格会推个人小剧情的 NPC。

## 7. 集体共建 — 可行性评估(基于现有代码,诚实结论)

**结论:能,但"共建"分三层,难度差 10 倍。**

| 层级 | 内容 | 现状 | 说明 |
|---|---|---|---|
| **L1 共建资产/玩法/技能** | 扫描造物、UGC 规则集、皮肤上传、二创繁殖+版税、Skill市场 | ✅ **基本现成** | World Engine 扫描、`WorldGameRuleSet`、`uploadSkin`/`breedPet`/版税、Skill 市场都已有,只差组织进"一个世界"外壳 |
| **L2 共建空间/地图** | 摆建筑、规划地块、装修房间 | 🟡 **需新建建造系统** | 缺:地块所有权 + 放置系统 + 权限。**是"集体共建城市"的主体工程**,但能复用 owner/资产/经济体系。移动端做轻量拖拽放置 |
| **L3 共建规则/治理** | 城市发展方向、税率、公共建筑、DAO | 🔴 **远期** | 有 AXP/钱包/Trust3/信誉的原材料,但治理产品很重 |

**端上直接共建的真正卡点不是"能不能造",而是"多人实时共建的同步架构"** —— 现在是离线
tick(回合制),实时同步是新架构,必须先做技术 spike 验证。

## 8. 尺度扩展:地球 → 火星 → 银河("纪元"运营框架)

- **真实地球地图当底图** —— 用开源地图(OpenStreetMap/MapLibre,免费可商用),三种用法:
  - (a) **选址/导航层**(最省最稳,推荐先做):地球图作最外层,用户在真实城市圈地建小镇/
    公司,点进去是 2.5D 等距场景。
  - (b) GPS 地理围栏(类 Pokémon GO,代入强但重,对定位/防作弊/隐私要求高,中期)。
  - (c) 全球协作数字孪生(远期愿景锚)。
  - 价值:自带地理社交 + 现实锚点(呼应 AI 眼镜)+ 话题。
- **火星 = 第二纪元**:地球建到一定繁荣度解锁。新主题皮肤+新资源+新挑战(拓荒/生存),
  底层仍是四原语。= 用世界观包装的"大版本更新 + 拉活"。
- **银河/外太空 = 第三纪元**:多星球世界=多社群/服务器,星际贸易/迁徙。长期扩展容器。
- **最大价值**:让"集体共建"有永远建不完的目标,解决共建类产品"建完没事干"的终局问题;
  每个纪元都是自带话题的大版本运营事件。
- 守住:**共建的东西要能产生真实价值或真实社交,不能是纯装饰。**

## 9. 红线 / 铁律(已拍板)

1. **真人和 agent 必须分得清** —— agent 驱动角色永远带可见标识(🤖徽章/描边/名字后缀·AI);
   三态(亲自✋/托管🤖/协同🤖+✋)实时可见;agent 的消息/任务/交易标注"由 XX 的 agent 执行"。
   这是合规底线,也做成信任特性(领先合规,To B 加分;"分得清"反而让"我的 agent 替我谈成
   一单"产生惊喜)。
2. **agent 自主社交/交易的边界** —— agent 可主动搭别人 agent 聊合作,但花钱/签约/高风险
   动作走 Trust3 签名 + Approval_Alert 闸门(已有)。
3. **真钱 = 合规重力** —— AXP(站内积分)先行;数字货币/提现/现实物资交易分阶段开关,
   涉及 KYC/反洗钱/税务/未成年人保护。
4. **体验好、能彻底落地 > 机制炫酷**(用户原话,定为最高优先级)。

## 10. 落地纪律(怎么保证体验好、能落地)

1. **一个原语做穿,不要十个场景做浅** —— 先把"房间"打磨到"两个人进去真的爽",上层场景
   都是配置。
2. **冷启动不空场(生死线)** —— **agent 填场**(你的/别人托管的 agent/NPC 撑场,这是
   Agentrix 独有的冷启动解法);**异步优先**(能异步别强求实时,实时是高光、异步是日常留存)。
3. **体验好 = 低延迟 + 不崩 + 一眼会用**(推广"怎么玩"教程到所有场景)。
4. **先把一个完整闭环跑通再扩** —— 10 个真实用户走完"发任务→agent接单→验收付AXP→提现"
   比 100 个 demo 有意义。
5. **内容/运营是产品的一部分** —— 冷启动期自办黑客松、自己当种子 OPC、招种子演员撑场,
   不能指望"建好了人就来"。

## 13. 关键决策(2026-05-31 用户已拍板)

1. **核心体验目标**:好玩、沉浸感强到"不想出来" + **能真的赚到钱(待定)**。
   → 真钱按 §9 红线分阶段:AXP 先行,数字货币/提现作为开关,合规就绪再开。
2. **第一个样板场景**:✅ **虚拟公司 / 任务广场**(价值实、最 Agentrix、不强依赖实时)。
3. **架构**:✅ **最好做实时架构** → "实时多人同步层" spike 排到最前,先验证可行性再铺。
4. **先做哪层**:判据 = **最能吸引玩家**(留存/拉新优先于技术省事)。
5. **共建层级 + 地图**:✅ **L2 空间共建** + **地球图作"宏观视图/选址"(用法 a)** —— 真实地球
   作最外层导航层,用户在真实城市圈地建自己的小镇/公司,点进去是 2.5D 等距场景。最省最稳。
6. **纪元框架(地球→火星→银河)**:✅ 作为产品版本路线骨架。
7. **美术基调**:🟡 **试"科技未来城"**(冷色/霓虹/AI 未来感),最终以实际效果为准,先出概念图验证。
8. **世界名字**:✅ 换名(不再用"星语小镇")—— 候选见 §14。

### 锁定后的 MVP 方向(综合 1-8)
> 真实地球地图选址 → 圈地建一座**可实时多人在场**的 **2.5D 科技未来城**;首发玩法是
