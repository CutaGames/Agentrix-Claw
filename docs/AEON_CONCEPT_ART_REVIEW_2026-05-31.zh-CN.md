# Aeon(永曜城)概念图验证 + 量产门禁 — Concept Art Review

> Task 5.1 / R15.1–15.5。量产美术前的"画风对齐 + 可读性"验证关卡。
> 本文是**门禁文档**:未通过则阻断 2.5D 等距贴图量产,记录备选方向。

## 1. 目标(Definition of Done)

在投入批量美术(等距 tilemap / 建筑贴图 / 室内背景)前,先用**少量概念图**验证:

1. "科技未来城"视觉基调成立(霓虹 + 等距 + chibi 友好)。
2. 现有 chibi 精灵(6 族群,`PetSpriteImage`)贴在等距背景上**读得清**(不糊、不违和、对比足够)。
3. 室内场景可用**静态背景 + 站位**表达(不做室内 3D,R15.4)。
4. 全局氛围用**单层昼夜/天气滤镜**即可(不逐物件打光,R15.5)。

## 3. 可读性测试方法(关键)

把现有 6 族群 chibi 精灵(A–F)以 `SPRITE_SIZE=48` 叠在 CA-1 / CA-3 上:

- [ ] 远景(整屏 ~20 个精灵)能区分角色轮廓。
- [ ] 头顶身份徽章(✋/🤖/🤖✋/🟣)在背景上清晰可辨(R3 铁律不能被背景吞掉)。
- [ ] 暗色霓虹背景下浅色精灵不过曝;浅色背景下深色精灵不糊。

## 4. 昼夜/天气滤镜(R15.5)

- 单层全屏滤镜(色温 + alpha 叠加),四档:晨/昼/暮/夜 + 可选雨雾。
- 不做逐物件光照、不做阴影系统。客户端一个 overlay View 即可,零额外美术。

## 5. 门禁判定(Gate)

- ✅ **通过** → 进入量产:批量出等距 tile + 建筑贴图 + 室内背景,替换 emoji 占位。
- ⛔ **不通过** → 阻断量产,在 §6 记录失败原因 + 备选方向(如:放弃等距改正交 2D / 降低霓虹饱和 / 加描边提升精灵可读性),下一轮重出概念图。

### 基调决议(2026-05-31)
- **最终基调 = "晨昏暖光 A'"**:暖色天空(蜜桃橙→淡紫渐变)+ **中性偏暗青蓝等距网格地面** +
  克制霓虹点缀(光柱路灯/霓虹树只在地块边缘)+ 漂浮岛发光蓝边界 + 中央 70% 留空可建造网格。
- 迭代过程:霓虹深夜版(太满/无留空,淘汰)→ 空地版(结构 OK)→ A/B/C 对比
  (A 晨昏暖光 / B 晴空 / C 粉彩)→ **A' = 晨昏暖光 + 地面降饱和压暗**(胜出)。
- 备选保留:**昼夜滤镜**——A' 中性底图叠夜间滤镜即还原"霓虹夜",一图四档氛围(晨/昼/暮/夜)。
- B(晴空)可读性最佳但氛围平;C(粉彩)与萌宠精灵最搭但浅色角色易糊。均作备选不作默认。

### 可读性实测(R15.3,已通过)
- 用豆包样张在 A' 地面中央叠了 **团子猫(纯白)/ 泰迪熊(焦糖)/ 灵狐(粉)** 三只 chibi:
  **全部清晰可辨,纯白角色未糊进背景。** 证明 A' 的明度/饱和度对 48px 精灵 + 身份徽章友好。
- 代码侧安全网:`AeonSceneScreen` 给每个角色精灵垫一层柔和半透明底盘(contact-shadow/光晕),
  保证任意房间背景下角色都能浮出 —— 纯代码零美术,防个别浅色皮在某些背景发灰。
