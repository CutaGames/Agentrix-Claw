# UI 草图 — 世界创作与浏览(World Creation & Feed)

> 低保真线框(ASCII),用于对齐交互与信息架构。关联:`./requirements.md`、`./design.md`
> 设计基调:深色主题(沿用现有 `theme/colors`)。底部为四大 Tab,本规格只改「世界」Tab。

## 屏幕清单

1. 世界 Tab 首屏 · 新用户
2. 世界 Tab 首屏 · 老用户
3. 创作流 Feed(类抖音,多类型卡片)
4. 统一世界地图
5. 创作器(单一动作:描述 → 生成 → 选址 → 发布)
6. 体验宿主(进入后:玩 / 买 / 看 / 聊)
7. 创作详情 / 留言 / 分享
8. 我的世界(我的创作 + 收益 + Agent 代付额度)

---

## 1) 世界 Tab 首屏 · 新用户(无创作)

目标:一眼看懂"这是个能创作、能逛、能玩的世界",且只给一个主行动。

```
┌─────────────────────────────────────────┐
│  🌍 世界                          🔍  🔔 │  ← 顶部:搜索 / 通知
├─────────────────────────────────────────┤
│  ┌─────────────────────────────────────┐│
│  │   和你的 AI 一起,造一个活世界          ││  ← Hero
│  │   描述你想要的场所/游戏/店铺            ││
│  │   ┌─────────────────────────────────┐ ││
│  │   │ 想造点什么?例如"开一家手冲咖啡馆"│ ││  ← 一句话即创作(主行动)
│  │   └─────────────────────────────────┘ ││
│  │          [ ✨ 让 AI 生成 ]            ││
│  └─────────────────────────────────────┘│
│                                           │
│  先逛逛大家创作的世界 ↓                     │
│  ┌──────────────┐  ┌──────────────┐       │
│  │ 🎬 刷创作流   │  │ 🗺️ 逛世界地图 │       │  ← 两个浏览入口
│  └──────────────┘  └──────────────┘       │
│                                           │
│  🔥 此刻热门                               │
│  ┌────┐┌────┐┌────┐  (横向滑动预览)        │
│  │游戏 ││超市 ││直播 │                      │
│  └────┘└────┘└────┘                       │
├───────────────────────────────────────────┤
│   世界      召唤      广场       我          │  ← 底部 Tab
└─────────────────────────────────────────┘
```

要点:主行动 = 一句话创作;次行动 = 刷流 / 逛地图;底部一条热门预览制造"有内容"的感觉。无战斗/副本/拍照3D 等入口。

## 3) 创作流 Feed(类抖音 · 全屏竖滑)

全屏沉浸,上下滑切换创作;右侧竖排互动;底部按**创作类型**给主行动。预览态轻量,点击主行动才重型进入。

```
┌─────────────────────────────────────────┐
│ ‹返回      🎬 创作流    [最新|热门|关注|附近]│  ← 顶部排序口径
│                                           │
│                                           │
│            (预览物:封面/短视频/回放)        │       ♡  1.2k   ← 点赞
│                                           │       💬  88    ← 留言
│              全屏沉浸预览区                  │       ↗  分享
│                                           │       👤 关注
│                                           │       ⋯  举报
│                                           │
│  ☕ 「深夜手冲咖啡馆」 @豆豆                  │  ← 创作者 + 标题
│  AI 生成 · 📍三里屯 · 🛒可下单               │  ← 标签:类型/地理/能力
│  ┌─────────────────────────────────────┐ │
│  │      🛒 进店下单(美式 ¥18 起)         │ │  ← 主行动(随类型变)
│  └─────────────────────────────────────┘ │
│         ▲ 上滑看下一个创作 ▲                │
└─────────────────────────────────────────┘
```

不同类型卡片的**主行动**(底部按钮随 `CreationType` 变):

```
game       →  [ ▶️ 开始玩 ]
shop       →  [ 🛒 进店下单 ]   (支持流内快捷下单,见下)
livestream →  [ 🔴 进入直播 ]   (进行中才高亮)
stage      →  [ 🎤 进入现场 ]
place      →  [ 🚪 进去逛逛 ]
```

shop 卡的**流内快捷下单**(不必进完整体验):

```
│  ┌─────────────────────────────────────┐ │
│  │ 🛒 美式  ¥18   [－] 1 [＋]   [ 下单 ] │ │  ← 流内直接交易(Economy_Bridge)
│  └─────────────────────────────────────┘ │
```

要点:预览 vs 进入分离(滑动只放预览物);右侧抖音式互动条;主行动随类型变;shop 可流内成交。

## 5) 创作器(单一动作 · 描述→生成→选址→发布)

一条主线,三档创作方式作为"继续编辑";offering/能力清单自动派生,创作者不碰接口。

```
┌─────────────────────────────────────────┐
│ ‹返回         ✨ 新建创作                  │
├─────────────────────────────────────────┤
│ ① 描述你想造什么                           │
│ ┌─────────────────────────────────────┐ │
│ │ 开一家手冲咖啡馆,卖美式18/拿铁22,      │ │
│ │ 可以预约座位                           │ │
│ └─────────────────────────────────────┘ │
│ 方式: (●提示词) ( 协同编辑 ) ( 手动搭建 )   │  ← 连续谱切换
│            [ ✨ 生成 ]                     │
│                                           │
│ ② 预览(AI 生成后)                         │
│ ┌─────────────────────────────────────┐ │
│ │  [场景预览图]   类型:shop 自动识别      │ │
│ └─────────────────────────────────────┘ │
│ 🧾 自动识别的供给(可改价):                 │  ← offering 自动派生
│  · 美式咖啡  ¥18   动词:下单/订阅          │
│  · 拿铁      ¥22   动词:下单               │
│  · 座位预约  —     动词:预约               │
│ 🤖 已自动生成 Agent 可调用能力(MCP):       │  ← 机器面自动,只读展示
│  query / order / book  ✓                  │
│                                           │
│ ③ 放到世界里(可选)                         │
│  [ 📍 选址到地图 ]   [ 仅放进创作流 ]        │
│  □ 绑定我的真实店铺(商家)                   │
│                                           │
│ ┌─────────────────────────────────────┐ │
│ │           [ 提交审核并发布 ]            │ │  ← 发布前过审 + 要求预览物
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

要点:用户只做"描述 + 改价 + 选址";offering 与 MCP 能力为系统自动派生(只读呈现,建立"我的东西 Agent 也能用"的认知);扫描素材作为可选输入(从"+"或描述区旁的 📷 进入,带质量门槛)。

## 6) 体验宿主(进入后:玩 / 买 / 看 / 聊)

进入任一 Creation 的统一宿主;按类型渲染主体,顶部统一返回,底部统一社交条。

```
┌─────────────────────────────────────────┐
│ ‹返回    ☕ 深夜手冲咖啡馆      [基底A] [L0]│  ← 标题 + Tier/隔离级
│                                           │
│            (体验主体区域)                   │
│   shop: 商品列表 + 结账                     │
│   game: 可玩画面 + 操作                     │
│   stage/live: 直播/现场 + 在场人            │
│   place: 可漫游场景                         │
│                                           │
│  — shop 示例 —                             │
│  美式咖啡   ¥18           [ 加入 ]          │
│  拿铁       ¥22           [ 加入 ]          │
│  ─────────────────────────────────        │
│  合计 ¥40           [ 结账(服务端权威) ]    │
├─────────────────────────────────────────┤
│  ♡ 点赞   💬 留言   ↗ 分享   👤 关注店主     │  ← 统一社交条
└─────────────────────────────────────────┘
```

异常:进入超时(>10s)→ 回退来源 + 提示 `LOAD_TIMEOUT`。

## 交互流贯穿(把五大支柱串起来)

```
创作:首屏一句话 / 创作器  ─┐
                          ├─▶ 发布(过审+预览物)─▶ 进入注册表
浏览:创作流(刷) / 地图(逛) ◀──────────────────────┘
进入体验:玩/买/看/聊  ─▶  交易(Economy_Bridge 权威)
社交:点赞/留言/关注/分享(深链)
机器面:Agent 检索 → invoke(query/order/book/message/subscribe/donate)→ 预设额度 → 审计
```
