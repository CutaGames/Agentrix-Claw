# Creator Studio MVP — Requirements

> 让桌面端成为创作者的一站式工作台：生成多形态 3D 萌宠 → 上架市场 → 生成配套宣传物料

---

## 用户故事

### US-1: 多形态萌宠生成
**作为**创作者，**我想**一次性生成同一角色的多种形态（萌态/专家态/商人态），**以便**我的宠物能根据使用场景自动切换外观。

**验收标准：**
- [ ] PetCreator 支持"生成变体"模式
- [ ] 用户输入基础描述后，可选择生成 1-3 种形态变体
- [ ] 每种形态有独立的 .glb/.vrm 模型文件
- [ ] 三种形态绑定到同一个 Soul，共享亲密度和记忆
- [ ] 桌面端浮球根据当前模式（Living/Pro/Economy）自动切换对应形态

### US-2: 皮肤上架到 Marketplace
**作为**创作者，**我想**把生成的萌宠皮肤直接从桌面端上架到市场，**以便**其他用户可以购买/使用我的作品。

**验收标准：**
- [ ] WardrobePanel 中每个皮肤有"上架到市场"按钮
- [ ] 上架表单：标题、描述、定价（AXP/USD）、标签、族群分类
- [ ] 预览页面展示 3D 模型 + 信息
- [ ] 提交后调用后端 `/api/v1/marketplace/skins/listing` API
- [ ] 上架成功后在 Marketplace 可见

### US-3: 海报生成器
**作为**创作者，**我想**基于我的萌宠快速生成宣传海报，**以便**在社交媒体分享推广。

**验收标准：**
- [ ] CreatorStudioHub 中有"海报工坊"入口
- [ ] 提供 5+ 预设模板（路演/社交/产品/节日/极简）
- [ ] 用户可自定义文案、颜色、布局
- [ ] 支持导入萌宠 3D 模型作为主视觉（截图渲染）
- [ ] 一键导出 PNG/PDF（1080×1920 / A4 / 自定义尺寸）

### US-4: PPT 生成器
**作为**创作者，**我想**通过对话让宠物帮我生成演示文稿，**以便**快速准备路演/汇报材料。

**验收标准：**
- [ ] Agent 模式下支持"帮我做 PPT"指令
- [ ] LLM 生成结构化大纲（标题/要点/数据）
- [ ] 基于模板自动生成 .pptx 文件
- [ ] 支持插入萌宠形象作为装饰元素
- [ ] 生成后可在桌面端预览 + 导出

### US-5: 视频脚本 + 生成
**作为**创作者，**我想**让宠物帮我生成产品宣传视频，**以便**用于社交媒体和官网。

**验收标准：**
- [ ] VideoStudioPanel 支持"从脚本生成"模式
- [ ] LLM 生成分镜脚本（画面描述 + 旁白 + 时长）
- [ ] 调用视频生成 API（Kling/Runway）生成片段
- [ ] TTS 生成配音
- [ ] 自动合成最终视频（FFmpeg）
- [ ] 导出 MP4（720p/1080p）

## 功能优先级

| 优先级 | 功能 | 依赖 | 预估周期 |
|:------:|------|------|:--------:|
| **P0** | US-1 多形态萌宠生成 | PetCreator 已有 | 2 周 |
| **P0** | US-2 皮肤上架 | 后端 API 已有 | 1 周 |
| **P1** | US-3 海报生成器 | 图像 API + Canvas | 2-3 周 |
| **P1** | US-4 PPT 生成器 | LLM + 模板引擎 | 2-3 周 |
| **P2** | US-5 视频生成 | 视频 API + FFmpeg | 4-6 周 |

---

## 非功能需求

- **性能**：3D 模型生成 < 90s（已有基线）；海报生成 < 10s；PPT 生成 < 30s
- **成本**：单次 3D 生成 ~$0.05-0.10（Meshy/混元3D）；视频生成 ~$0.50-2.00/分钟
- **离线**：海报/PPT 模板引擎可离线工作；3D/视频生成需联网
- **格式**：3D 输出 .glb/.vrm；海报 PNG/PDF；PPT .pptx；视频 MP4
