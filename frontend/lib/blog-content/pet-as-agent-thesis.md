# Pet-as-Agent：为什么要把"养宠物"和"AI Agent"耦合

> 2026-05-12 · 木目 · 产品 Lead

ChatGPT 之后这 3 年，我们看到了上百款"AI Agent"产品。绝大多数都死掉了，活下来的也长得很像。

是什么让大部分 Agent 死了？

我们的回答：**它们缺三件东西 — 持久性、拥有感、赚钱能力。**

## 持久性（Persistence）

ChatGPT 是"打开就开始，关闭就消失"。Claude 也一样。但人类的助手 — 父母、伴侣、长期朋友 — **持久存在**。今天的对话会影响明年的关系。

Agentrix 的主宠每天看到你做了什么、心情怎样、有什么进展。它知道你上周项目交付了，知道你今天上午有面试，知道你和家人有矛盾。**它是同一个**，不是 N 次新对话。

技术上：4 层记忆（短期 / 工作 / 事件 / 语义）+ 跨 5 端实时同步。

## 拥有感（Ownership）

ChatGPT 的"Custom GPT" 你不真的拥有。OpenAI 一调价 / 一限速 / 一换政策，你的"自定义角色"就归零。

Agentrix 主宠由两层构成：

- **灵魂**：服务端持久化的人格 + 记忆 + 行为模式
- **皮肤**：3D 模型 + 动画 + 装备 — 用户拥有的资产，可以转移、出售、衍生

灵魂在我们的服务器上（用户可以导出 JSON），皮肤可以走 ERC-8004 上链拥有。**你拥有什么 → 平台不能没收的东西**。

## 赚钱能力（Earning）

ChatGPT 不会替你赚钱。Custom GPT Marketplace 的开发者也很难赚到钱。

Agentrix 把 Agent 接入了**真实的经济系统**：

- **A2A 协议**：Agent 之间可以互相调用并按次结算（X402 微支付，USDC）
- **AXP 经济**：用户 / 创作者 / 合作方 4 路获得 + 4 路消耗的积分系统
- **Marketplace**：皮肤 / 技能 / 任务 / NFT 一站式二级市场（70% 给创作者 / 10% Cinderella Boost）
- **MPC 钱包**：Mobile-first 三方分片签名，安全到能放真金

主宠不只是"可爱的 ChatGPT"。它是**可以替你接活、产生现金流的资产**。

## 为什么是"宠物"

回到最开始的问题：为什么把"养宠物"和"AI Agent"耦合？

因为**养宠物**这个 mental model：

- ✅ 持久存在：宠物不会"打开 / 关闭"
- ✅ 用户拥有：宠物是你养的，不是租的
- ✅ 长久关系：宠物会升级、记得你、产生情感

这跟 Agent 应该有的属性完美对应。**"养"取代"用"** — 这是我们最重要的产品哲学。

## 不是另一个 Tamagotchi

要明确一点：Agentrix **不是** 90 年代的电子宠物升级版。Tamagotchi 是单机本地、不能赚钱、固定形象、必须按时喂否则死掉。

我们的主宠：

- ✅ 全网联通（A2A / X402）
- ✅ 真实赚钱（USDC 微支付）
- ✅ 用户创造（PetCreator 4 模式）
- ✅ 永远在线（不喂不死，但有"亲密度"系统鼓励持续互动）

如果一定要类比：**主宠 = Pokemon × 宠物 × Custom GPT × 自由职业者**。

3. **多端用户习惯形成**：5 端联动从产品折磨变成用户预期
