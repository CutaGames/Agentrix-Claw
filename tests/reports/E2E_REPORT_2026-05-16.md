## 5. 发现的问题

### Critical (P0)

无。生产环境所有关键路径正常。

### High (P1)

无。

### Medium (P2)

1. **Mobile typecheck 22 个 pre-existing 错误** — 在 `HomeStackNavigator.tsx` / `BreedScreen.tsx` / `clawcore/firmwareSigning.ts` / `nfc.service.ts` / `axpCashback.service.ts` 等文件。这些是之前 Sprint 留下来的，本轮工作没有引入新错误。建议下个 cleanup sprint 集中修复。
   - 例：`HomeStackNavigator(192,9): "NftMint" not in HomeStackParamList` — 漏注册 type
   - 例：`BreedScreen(86,9): biasTowardA does not exist in type` — API shape 改了没同步

2. **`/showcase` 307 redirect** — 历史 redirect 到 `/market`（Phase 3 P2-5 navigation consolidation）。smoke test 已 accept 307。如果之后想保留 `/showcase`，需要从 `next.config.js` redirects 移除。

3. **Lighthouse 性能** — 上次审计 `LIGHTHOUSE_mobile_2026-05-16.md` 发现：
   - 平均 perf 63（目标 80）
   - `/market/leaderboard` perf=36（最差，LCP 11.1s）— 需 SSR 首屏数据
   - 平均 LCP 3.9s vs 目标 2.5s
   
   非阻塞 GA，但 GA 后第一波优化的明确 target。

4. **iOS asset-app-site-association 仍含 `TEAM_ID.com.agentrix.claw` 占位**（应为 `app.agentrix.claw`）— 在跳过 iOS sprint 时遗留；Android 相关已修。

### Low (P3)

5. **`marketplace-pet/phase3-e2e.spec.ts`** Postgres 容器测试在 dev sandbox 卡住 — CI 上跑应正常。
6. **后端 jest 报 worker not exit gracefully** — 可能是 timer 没 unref。不影响测试结果，但日志需清理。
